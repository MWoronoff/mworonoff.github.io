Apartment Management Market Analyzer

National screening tool for acquisition, disposition review, portfolio fundamentals, marketing need and B2B opportunity. Built as a standalone application; it does not depend on or modify the existing Panda or ZIP Radius sites.

Screening-score note: The enhanced Acquisition and Disposition scores add a renter-demand-depth proxy and a supply-pressure proxy using recent construction (units built 2020+) plus vacancy. These improve directional screening but are still not property valuations, cap-rate forecasts or transaction recommendations. True historical rent/vacancy trends and active multifamily pipeline data remain desirable for final underwriting.

Property marketing methodology: every ZIP in the selected radius remains in the ranking. The Property Marketing Score blends Property Advertising Score, renter-household scale within the selected radius, Marketing Need, and proximity to the property. The campaign-objective selector changes those weights. Suggested budget then applies an additional distance-decay factor so closer ZIPs receive more weight when otherwise similar. This is a media-planning aid, not a required spend prescription.
Current data source: Apartment Management Market Opportunity workbook. Nationwide results currently include 939 metros/CBSAs and 3,199 counties. This build includes national metro/county rankings, market comparison, export, and the property ZIP-radius advertising module with campaign-objective scoring and distance-decayed budget allocation. Enhanced screening now incorporates demand-depth and recent-construction/vacancy supply-pressure proxies. True historical rent/vacancy series and active multifamily pipeline data remain the next major underwriting enhancement.
